# Подход: спецификация продукта

Русскоязычный мобильный журнал тренера зала для одного тренера на одном телефоне. PWA открывается по ссылке на GitHub Pages, добавляется на главный экран и после первого входа загружается без интернета. Рабочие данные хранятся локально в браузере, без аккаунта, сервера и синхронизации. Журнал учитывает полученные деньги, но не принимает онлайн-платежи. Посещения не считаются.

Стек: React, TypeScript, Vite, IndexedDB, Vitest. Деньги хранятся целыми копейками, даты абонементов календарные, без времени. Схема базы версионируется, обновления сохраняют данные. Интерфейс простой, мобильный; статусы различаются не только цветом. Проверки только на вымышленных данных. Границы реализации по окнам описаны в ROADMAP.

## Клиенты

- Основной список, отдельная карточка и форма нового клиента. Имя, фамилия, телефон и заметки необязательны. Карточка сохраняется без абонемента. Поиск сверху фильтрует сразу по началу имени или фамилии без учёта регистра. Данные сохраняются после перезапуска.
- Просрочка и неактивность не скрывают клиента автоматически. В основном списке можно выбрать одного или нескольких клиентов для архивации или удаления. Архив отдельный, с поиском, возвратом и удалением. Архивация не меняет историю или сроки.
- Перед удалением показать всех выбранных и запросить явное подтверждение. Удалять клиента и связанные записи одной транзакцией по мере добавления сущностей.

## Тарифы, абонементы и платежи

- «Настройки → Тарифы»: создание и редактирование названия, цены (включая ноль) и срока (положительное целое число дней или календарных месяцев). Пробный, месяц, три месяца, полгода и год можно настроить, но список не жёстко задан. Убранный из выбора тариф остаётся в истории. Снимок цены и длительности периода неизменен при правке тарифа.
- При добавлении клиента и из карточки можно оформить абонемент или перенести действующий с известной датой следующей оплаты, без фиктивного платежа и доплаты. Можно сохранить только карточку. Для нового абонемента цена подставляется, срок виден до сохранения, начало по умолчанию сегодня и редактируется. При продлении предложить текущий доступный тариф. Досрочно срок прибавляется к текущей дате следующей оплаты, после просрочки к дате платежа. Календарные месяцы прибавляются одной операцией с ограничением последним днём целевого месяца.
- Карточка показывает тариф, сроки, статус, заметки и историю платежей. Фактические взносы отдельными записями: при цене 3 000 ₽ и взносе 2 000 ₽ показать «Осталось доплатить 1 000 ₽». «Внести доплату» не продлевает срок; «Продлить» создаёт новый период. Исправление платежа пересчитывает зависимости либо явно блокируется, если безопасный пересчёт невозможен.
- Сортировка: просроченные, оплата сегодня, ближайшие три дня, остальные по ближайшей дате, затем без абонемента. Доплата отмечается отдельно, это не статус просрочки.

## Заморозка

В карточке задаются начало и день возвращения; паузу можно запланировать и завершить досрочно. День возвращения не входит в паузу: 5→10 добавляет 5 дней, возврат 8-го добавляет 3. Запрещены пересечения и начало вне действующего периода. На паузе показывать «Заморожен» и дату возвращения, не относить к просроченным. Хранить историю. Уже оплаченный следующий период сдвигать на дни паузы без потери оплаченных дней и без повторного начисления.

## Файловые бэкапы

- Зашифрованный экспорт всего журнала (клиенты, архив, заметки, тарифы, периоды, платежи, заморозки, настройки). Формат версионируется, шифрование стандартное аутентифицированное. Не хранить пароль в базе или рядом с копией. «Скачать» и «Поделиться» через системное меню телефона (например, Telegram и облака, если доступны); если передача файла не поддерживается, остаётся скачивание. Открытие меню не подтверждает доставку. При открытии напоминать о копии, если её не делали или прошло семь дней.
- Импорт работает без GitHub: проверка пароля, формата и связей; показать дату и сводку; предупредить о полной замене и возможном возврате удалённых после копии клиентов; предложить сначала экспортировать текущий журнал. Импорт одной транзакцией, при любой ошибке база неизменна.

## Установка и публикация

Manifest, иконки, установка и офлайн-загрузка. GitHub Actions публикует на `https://<логин>.github.io/podhod/`; учесть `/podhod/` в сборке, ссылках и service worker. Проверить опубликованный HTTPS: первый вход, перезапуск без сети, обновление с сохранением базы. Дать ссылку и инструкцию установки для Android и iPhone; явно различать реальные телефоны и эмуляцию.

## Необязательные копии на GitHub

- Выключены по умолчанию. Только по кнопке отправляется зашифрованный файл в отдельный приватный `podhod-backups`; проверять приватность перед загрузкой, при невозможности проверки не отправлять. Хранить во вложениях релиза, не в Git-коммитах. Ключ ограничен репозиторием копий, только в оперативной памяти на время работы; не в сборке, логах, базе или экспорте.
- Показать количество, даты копий, время последней проверки, кнопку обновления. Лимит 1 или 5, по умолчанию 5 при подключении. Подтвердить загрузку новой прежде удаления старейших копий приложения; снижение лимита требует подтверждения очистки. При сбое показать фактическое число и возможность повторить. Посторонние файлы не трогать.
- Проверить загрузку, список и очистку из опубликованного приложения. Новый телефон: открыть приватный репозиторий, скачать файл, импортировать с паролем копии. Без GitHub скачивание, «Поделиться» и импорт работают как раньше.
