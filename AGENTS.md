# Продолжение работы над «Подходом»

Работай только в `D:\Pr\podhod`. В новом окне сначала прочитай `docs/SPEC.md`, `docs/ROADMAP.md`, `docs/STATUS.md`, затем проверь `git status`, последние коммиты и состояние ветки на `origin` (fetch и сравнение, если ветка существует). Не перезаписывай чужие правки. При команде «Продолжи „Подход“» выполняй только один этап за окно: если предыдущий не завершён или не отправлен, сначала закрой его и не начинай следующий в этом окне. Для текущего прогона DevConductor используй установленный `C:\Users\qwerty\.config\kilo\skills\devconductor\SKILL.md` и его состояние для этого пути; долговременные требования хранятся в SPEC.

Закрытие этапа: тесты, проверка типов, сборка, новый пользовательский сценарий в браузере на мобильной ширине. Обнови STATUS после каждой попытки закрыть этап, включая фактические результаты, проблемы и следующий этап. После успешных проверок коммить только файлы этапа, отправь коммит, проверь его на GitHub и дай ссылку. Не считай этап закрытым при неудавшейся проверке или пуше. Публичный репозиторий предназначен только для кода и документации; никого не тестируй на настоящих данных. Не коммить клиентские данные, копии, токены, пароли и локальные секреты. Не делай существующий приватный репозиторий публичным без подтверждения и не используй чужой репозиторий.
